# Dataset Research - 2026-05-29

Rule for this project: do not recreate datasets when public datasets already
cover the need. Local artifacts should be sampling manifests, transforms, and
dedup/filter metadata only.

## Recommended v0 Dataset Stack

### Router/expert warmup

- `HuggingFaceFW/fineweb-edu`, preferably `sample-10BT` for first pass.
- Purpose: generic language modeling continuity after dense MLPs become routed
  experts.
- Use with `pyarrow.parquet` or streaming readers. Avoid `datasets` on system
  Python.
- Source note: FineWeb-Edu filters FineWeb with an educational-quality
  classifier and releases the filtered educational dataset publicly.

### General SFT / chat behavior

- `HuggingFaceTB/smol-smoltalk`
- `SL-AI/GRaPE-Base-Mix`
- Purpose: conversational behavior, instruction following, tool use, long
  context, and broad SFT formatting.
- Source note: Smol-SmolTalk was adapted for small models and used for SmolLM2
  instruct models. GRaPE Base Mix has 3,033,373 rows and covers code, math,
  instruction following, tool usage, and long context.

### Reasoning / code / math

- `open-thoughts/OpenThoughts3-1.2M`
- `nvidia/OpenMathReasoning`
- `nvidia/OpenCodeReasoning`
- `SL-AI/GRaPE-Thinking-Mix`
- Purpose: math/code/science reasoning traces and competitive programming
  distillation.
- Source note: OpenThoughts3 has 1.2M rows, with math/code/science questions
  annotated by QwQ-32B. OpenMathReasoning has millions of CoT/TIR/generated
  math solutions. OpenCodeReasoning has 735,255 Python competitive programming
  samples generated by R1.

## What We Should Create Locally

Only create:

- dataset manifests with exact repo, split, columns, sampling weight, and seed;
- schema adapters that map public columns into Qwen chat/completion formats;
- small cached samples for smoke tests;
- dedup/filter logs.

Do not create a synthetic dataset until we have proven that existing public
sets cannot cover a specific gap.

## Initial Sampling Recipe

For the first router/expert warmup:

- 50% FineWeb-Edu sample text continuation
- 20% Smol-SmolTalk / GRaPE Base general SFT
- 15% OpenThoughts3 reasoning
- 10% OpenCodeReasoning
- 5% OpenMathReasoning or GRaPE Thinking

For the first distill pass:

- Use public prompts/questions from the same datasets.
- Generate only teacher responses/logits as needed.
- Store teacher outputs as derived run artifacts with source prompt IDs, not as
  a new standalone dataset.
